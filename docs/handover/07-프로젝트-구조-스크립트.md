# 프로젝트 구조·운영 스크립트

## 루트 구조

```
donggori/
├── app/           # 페이지 + API
├── components/    # UI
├── contexts/      # AuthContext
├── lib/           # 비즈니스 로직
├── prisma/        # 스키마 참고용
├── scripts/       # 운영 스크립트·SQL
├── docs/handover/ # 인수인계 문서
├── middleware.ts
└── env.example
```

---

## app/ 주요 경로

### 사용자

| 경로 | 기능 |
|------|------|
| `/` | 메인 |
| `/factories` | 공장 찾기 |
| `/matching` | 맞춤 추천 |
| `/design-request` | 디자인 의뢰 |
| `/notices` | 공지 |
| `/sign-in`, `/sign-up` | 인증 |
| `/my-page` | 마이페이지 |

### 관리자

| 경로 | 기능 |
|------|------|
| `/admin/login` | 로그인 |
| `/admin` | 대시보드 |
| `/admin/factories` | 업장 CRUD·Excel |
| `/admin/notices` | 공지 |
| `/admin/popups` | 팝업 |

### API

`auth/`, `admin/`, `factories/`, `notices/`, `popups/`, `match-requests/`, `feedback/`

`factory/`, `/factory-my-page`, 공장 로그인/세션, `factory-images/*`, 공장 알림톡/SMS 경로는 제거된 레거시다.

## 삭제된 레거시 (2026-06-29)

| 항목 | 비고 |
|------|------|
| Clerk 인증 | 커스텀 세션으로 대체됨 |
| 토스페이먼츠 SDK | 미연동 |
| 강좌 (`/courses`, `/my-courses`) | 미사용 |
| AI 모델핏·의류생성 | 미출시 |
| Google OAuth (`/v1/oauth_callback`) | 미사용 |
| 디버그 페이지 (`/debug-*`, `/test-*`) | 개발용 제거 |
| 공장 로그인·대시보드·세션 | 관리자가 공장 정보를 등록하는 운영 구조로 변경 |
| 공장 이미지 직접 업로드·삭제 | 관리자 공장 API로 통합 |
| 공장 알림톡/SMS 자동발송 | 중앙 오픈채팅 안내로 변경 |

## 팝업 운영 참고

- GET `/api/admin/popups`에서 자동 시드 **없음**
- 수동 시드: `POST /api/admin/popups/seed`
- 중복 정리: `POST /api/admin/popups/dedupe`
