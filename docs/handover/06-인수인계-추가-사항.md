# 3. 추가 인수인계 요청 사항

## 3-1. 데이터베이스

### 백업

- Supabase Dashboard → Database → Backups
- 수동: `pg_dump` 또는 Supabase CLI

### 복구

1. 백업 시점 선택 또는 SQL import
2. env URL/키 확인
3. 관리자·공지·팝업 smoke test

### 접속 정보 (별도 보안 채널 전달)

| 항목 | env 변수 |
|------|----------|
| Project URL | `NEXT_PUBLIC_SUPABASE_URL` |
| service_role | `SUPABASE_SERVICE_ROLE_KEY` |

직접 DB 연결이 필요한 일회성 백업 작업은 Supabase Dashboard에서 연결 문자열을 확인하며, 애플리케이션 환경변수로 상시 보관하지 않습니다.
