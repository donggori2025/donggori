## 1-1. 프론트엔드(퍼블리싱) 개발 산출물

### 전체 개발 원본 소스 코드

- app/ — Next.js App Router 페이지 및 API 라우트 (프론트+백엔드 통합)
- components/ — UI 컴포넌트 (Header, Footer, 지도, 팝업, admin-ui 등)
- contexts/ — React Context (AuthContext: 인증 상태)
- lib/ — 비즈니스 로직, 유틸, 타입
- public/ — 정적 자산 (OAuth 아이콘, 이미지 등)
- app/globals.css — Tailwind CSS 4 스타일

### 주요 사용자 페이지

- / — 메인 랜딩
- /factories — 봉제공장 찾기 (목록, 필터, 지도)
- /factories/[id] — 공장 상세
- /factories/[id]/request — 작업 의뢰 (작업지시서)
- /matching — AI 매칭
- /design-request — 디자인 의뢰
- /work-order — 작업지시서 안내
- /notices, /notices/[id] — 공지사항
- /sign-in, /sign-up — 로그인, 회원가입
- /my-page/* — 마이페이지 (프로필, 문의)
- /factory-my-page/* — 공장 사장님 마이페이지
- /faq, /service, /terms/[type] — 정적 안내 페이지

### 현재 운영 중인 최신 버전

- 브랜치: main
- 배포: Vercel Git 연동 자동 배포 (push 후 build, deploy)
- 주요 기능: 관리자 UI, 팝업 DB 관리, 업장 Excel 추출, AI 매칭, 디자인 의뢰

### 빌드 및 배포 설정 파일

- package.json — 의존성, npm scripts
- next.config.ts — 이미지 remotePatterns, 보안 헤더, webpack
- tsconfig.json — TypeScript 설정
- postcss.config.mjs — PostCSS (Tailwind)
- components.json — shadcn/ui 설정
- middleware.ts — donggori.com, donggori.kr → www.donggori.com 리다이렉트
- prisma/schema.prisma — Prisma 스키마 (빌드 시 generate, 런타임 미사용)
- env.example, docs/handover/.env.example — 환경 변수 템플릿

### 빌드 명령

```
npm install
npm run build
npm run start
npm run dev
```

- npm install: postinstall에서 prisma generate 실행
- npm run build: prisma generate 후 next build
- npm run dev: Turbopack 개발 서버

## 1-2. 서버(Backend) 및 DB 개발 산출물

### 서버 개발 원본 소스 코드

Next.js App Router API Routes (app/api/)가 백엔드 역할을 합니다. 별도 Express/Nest 서버는 없습니다.

**API 영역**

- /api/auth/* — 로그인, 카카오/네이버 OAuth, 이메일 OTP, 비밀번호
- /api/admin/* — 업장, 공지, 팝업 CRUD, 통계, Excel 추출
- /api/factory/* — 공장 사장님 로그인, 정보 수정
- /api/factories, /api/notices, /api/popups — 공개 API (개인정보 마스킹)
- /api/match-requests, /api/requests/* — 작업지시서, 알림
- /api/factory-images/* — Vercel Blob 이미지 업로드/삭제/프록시
- /api/feedback — AI 매칭 피드백

상세 API 목록: 03-API-문서.md 참조

### DB 마이그레이션 파일

- prisma/schema.prisma — User, FactoryAuth, PhoneOtp (참고용)
- scripts/create_admin_tables.sql — popups, notices 테이블
- scripts/create-email-otps-table.sql — email_otps
- scripts/factory_auth.sql — factory_auth, 샘플 계정
- scripts/add_popup_slug.sql — popups slug, link_url_mobile
- scripts/add_popup_link_url.sql — popups link_url
- scripts/add-category-to-notices.sql — notices category
- scripts/add-image-urls-to-notices.sql — notices image_urls
- scripts/seed_default_popups.sql — 기본 팝업 시드
- docs/db-migration-sql.md — sessions, message_logs 등

**운영 DB 핵심 테이블**

donggori (봉제공장 328건+), users, sessions, notices, popups, match_requests, message_logs, matching_feedback, email_otps

### 배포 설정

- Vercel: Framework Preset = Next.js, Build Command = npm run build
- vercel.json 없음 (Vercel 기본 설정)
- GitHub Actions CI 없음

### 스케줄러, 크론 작업

- 구현 없음
- 데이터 보강, Excel import/export는 scripts/ 수동 실행
- 예: npm run export:factories

## 1-3. 관리자(Admin) 개발 산출물

### 관리자 페이지 소스 코드

- /admin/login — app/admin/login/page.tsx (관리자 로그인)

**공통 레이아웃**

- app/admin/(dashboard)/layout.tsx
- app/admin/(dashboard)/AdminSidebar.tsx

**공통 UI**

- components/admin/FactoryEditDrawer.tsx

- 쿠키: admin_session (HMAC 서명, ADMIN_SESSION_SECRET)
