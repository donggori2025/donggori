# 2-3. 설치 및 배포 가이드

## 사전 요구사항

- Node.js 20.x
- npm 10.x
- Supabase 프로젝트
- Vercel 계정 (프로덕션)

---

## 로컬 개발

```bash
git clone https://github.com/donggori2025/donggori.git
cd donggori
npm install
cp docs/handover/.env.example .env.local
# .env.local 값 입력
npm run dev
```

- 로컬: `http://localhost:3000`
- 관리자: `http://localhost:3000/admin/login`

---

## 빌드

```bash
npm run build
npm run start
```

---

## Vercel 배포

1. GitHub 저장소 연결
2. Framework: Next.js
3. Build: `npm run build`
4. Environment Variables: `docs/handover/.env.example` 기준 등록
5. Production `NEXT_PUBLIC_SITE_URL=https://www.donggori.com`
6. Domains: `www.donggori.com`, `donggori.com`

`main` push → 자동 Production 배포

---

## OAuth Callback (프로덕션)

| 제공자 | URL |
|--------|-----|
| 네이버 | `https://www.donggori.com/api/auth/naver/callback` |
| 카카오 | `https://www.donggori.com/api/auth/kakao/callback` |

개발: `http://localhost:3000/api/auth/{provider}/callback`

상세: `docs/deployment-oauth-setup.md`

---

## 운영 반영 절차

1. `main` merge → Vercel 자동 배포
2. DB 변경 시 Supabase SQL 적용 후 코드 배포
3. env 변경 시 Vercel Redeploy
4. 데이터 일괄: `npm run export:factories`, `scripts/importFactoriesFromXlsx.js`

---

## 트러블슈팅

| 증상 | 확인 |
|------|------|
| 관리자 로그인 실패 | `ADMIN_ID`, `ADMIN_PW`, `ADMIN_SESSION_SECRET` |
| 소셜 로그인 실패 | OAuth Redirect URI ↔ `NEXT_PUBLIC_SITE_URL` |
| 이미지 업로드 실패 | `BLOB_READ_WRITE_TOKEN` |
| API 500 | `SUPABASE_SERVICE_ROLE_KEY` |
