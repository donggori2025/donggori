# 개인정보 고지 정합성 점검

## 코드에서 바로 고친 항목

- 실제로 제공하지 않는 공장 알림톡·SMS 발송 목적과 수탁자 문구를 제거했다.
- 회원가입·마이페이지에서 사용되지 않는 마케팅/카카오 메시지 동의를 수집하거나 수정하지 않게 했다.
- 처리 항목을 현재 코드가 저장하는 회원정보, 소셜 식별자, 문의정보 기준으로 정리했다.
- 공장 문의 뒤 카카오 오픈채팅으로 이동할 때 웹사이트가 회원정보나 문의를 자동 전송하지 않는다는 점을 명시했다.
- 공개 공장 API에서 상세 주소를 제외하고, 지도 좌표도 소수 둘째 자리로 낮춰 건물 단위 위치가 드러나지 않게 했다.
- 구현 근거가 없던 물리적 감시·백신·정기 감사 같은 포괄적 보안 주장을 실제 적용한 해시, TLS, 서버 API, 접근 통제 설명으로 교체했다.

## 운영 확인 후 반드시 보완할 항목

아래는 코드만 보고 확정할 수 없으므로 Production 반영 전 개인정보 보호책임자와 실제 공급자 계약을 기준으로 검토해야 한다.

1. Vercel, Supabase, 이메일 발송 공급자의 실제 법인명·연락처·처리 리전과 재위탁자
2. 국외 이전이 발생하는 개인정보 항목, 국가, 이전 시기·방법, 이전받는 자, 목적, 보유기간, 거부 방법과 효과
3. 회원정보·문의내역·접속로그별 정확한 보유기간 및 정기 파기 절차
4. 탈퇴/삭제 요청 접수 뒤 실제 DB·세션·문의·백업에서 처리하는 담당자와 완료 기한
5. Vercel Analytics와 기타 쿠키가 실제로 수집하는 값 및 쿠키 거부 방법
6. 개인정보 보호책임자 성명·직책·이메일이 현재도 유효한지 여부
7. 카카오·네이버 OAuth가 제공하는 실제 동의 항목과 공급자 정책 링크

개인정보 보호법 제28조의8은 국외 처리위탁·보관이 필요한 경우 처리방침 공개 등의 요건을 두고 있으며, 고지에는 이전 항목, 국가·시기·방법, 이전받는 자, 목적·보유기간, 거부 방법 등이 포함될 수 있다. 공급자 리전과 계약을 확인하지 않은 채 임의의 국가나 기간을 코드에 적지 않았다.

## 반영 절차

1. 위 운영 정보를 확정한다.
2. 개인정보 보호책임자 또는 법률 검토자가 `app/terms/[type]/page.tsx`의 개정안을 승인한다.
3. 현행 처리방침이 정한 방식에 따라 변경사항과 시행일을 사전 공지한다.
4. 시행일에 코드와 공지를 함께 반영한다.
5. 사용하지 않는 기존 `kakaoMessageConsent` 값/컬럼은 백업 후 별도 DB 변경으로 제거한다.
