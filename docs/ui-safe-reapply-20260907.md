## 구현 기록

1. 새 브랜치를 정상 main에서 생성하고 읽기 전용 비교로 기준을 고정.
2. 콘텐츠·자산·표현 전용 컴포넌트만 선별 적용. 한글 조합 중 Enter 입력을 보호.
3. 홈 공장 카드는 기존 서버 조회·실제 데이터 배지·실패 이미지 대체를 재사용. 자동 타이머 대신 직접 스크롤과 이전/다음 버튼 사용.
4. 공장/문의/추천/관리자 화면은 JSX className 문자열만 선별 변경. 인증·DB·계산 코드와 설정은 불변 비교.
5. 기존 sitemap의 공장·공지 상세 URL을 유지한 채 News·ESG를 추가하고 개별 canonical 지정.
6. ESG의 확인되지 않은 전국 9개 특구 연계·AI 매칭 단정을 제거하고 서비스 방향을 설명하는 문구로 정리.

Preview `dpl_Ccn353du4ya4xADLgB4f1Kw8Zyra`의 서버 응답은 인증된 Vercel CLI로 확인했다. 브라우저 Preview 인증을 완화하지 않았다. UI는 같은 후보 코드를 로컬에서 실행하고, 변경되지 않은 공개 조회 GET만 운영 API로 연결한 루프백 프록시로 확인했다. 1280px 홈과 390px ESG/공장 상세에서 가로 넘침 및 완료된 이미지의 깨짐이 없었고, 확인한 브라우저 콘솔에 오류가 없었다. 실제 소셜 계정 로그인 완료·문의 저장은 계정 소유자의 운영 확인 항목으로 남긴다. 운영 데이터 변경이나 환경변수 다운로드는 하지 않았다.
