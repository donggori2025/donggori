## 1. 과업 개요

### 1.1 과업명

**2026년 동대문구 봉제업체 실태조사 및 동고리 DB 구축**

### 1.2 과업 목적

동대문구 내 봉제업체에 대한 실태조사를 수행하고, 그 결과를 「동고리」 플랫폼 데이터베이스에 반영함으로써 디자이너–봉제업체 매칭·추천 서비스의 기반을 강화하는 것을 목적으로 한다.

### 1.3 과업 범위

- 봉제업체 실태조사(협회 회의·지원센터 정기조사·희망 업체 인터뷰)
- 동고리 DB 확충(목표 300개 업체) 및 카테고리·태그 체계 정비
- 동고리 플랫폼 서버 안정화 및 매칭 시스템 연동
- 플랫폼 UI/UX 개선 및 오류 보완
- 결과 데이터 리스트 및 최종보고서 제출

## 2. 주요 사업내용

### 2.1 사전 준비

#### (1) 사전 질문지 구성
- 동대문구 의류봉제 산업연합회, DDM 패션봉제 산업연합회, 동대문 패션봉제산업 발전협의회 등 3개 협회 의견을 반영하여 질의서 초안을 작성하였다.
- 협회 1차 피드백, 발주기관·전문기관 2차 피드백을 반영하여 최종 설문 양식을 확정하였다.

#### (2) 인터뷰 업체 리스트 수령
- 협회별 사전 리스트를 수령하여 조사 대상 업체 풀을 구성하였다.
- 네이버 폼·Airtable·스프레드시트를 활용한 수집·공유 체계를 마련하였다.

#### (3) DB 구축 필수 데이터 정의
- 과업지시서 메타데이터 구조(기본정보, 업장소개, 생산형태, 보유역량, 설비, 업장 프로필)를 기준으로 플랫폼 DB 스키마를 설계하였다.
- 디자이너 매칭·봉제업체 추천·실시간 알림 서비스에 필요한 필드를 선별·정의하였다.

### 2.2 운영

#### (1) 업체 인터뷰 및 데이터 수집(목표 300개)

| 수행 항목 | 내용 |
|-----------|------|
| 협회별 월 회의 방문 설문 | 2회차 진행 |
| 패션복지지원센터 정기 회의 | 2회차 진행 |
| 질의서 작성 및 피드백 | 협회·구청 피드백 반영 |
| 희망 업체 개별 인터뷰 | 데이터 수집·보완 진행 |
| **최종 DB 등록** | **328개 업체** |

#### (2) 데이터 태그 도출 및 리뉴얼

- 구청·협회·기관 자료와 인터뷰 결과를 통합하여 카테고리 체계를 정비하였다.
- 생산품목(상의·하의·아우터·원피스/스커트·가방·소품·속옷·스포츠/레저·애견), 업태, 유통, 설비 등 다중 선택 태그 구조로 DB를 구성하였다.
- 자동 보강 스크립트를 통해 **316개 업체**의 미입력 품목·설비 필드를 보완하였다.
- 외부 검색·휴리스틱 기반 보강 작업 **216건** 중 **213건** 필드 보완 완료.

#### (3) 플랫폼 구축·연동

- **기술 스택**: Next.js(App Router), React, TypeScript, Tailwind CSS, Supabase(PostgreSQL)
- **배포**: Vercel 기반 프로덕션 운영(donggori.com)
- **주요 기능**: 봉제공장 찾기, AI 매칭, 업장 상세, 디자인 의뢰, 공지사항, 회원가입/로그인(카카오·네이버·Clerk)
- **데이터 관리**: xlsx/CSV 일괄 등록·보내기 스크립트, 카테고리 보강·이미지 매핑 자동화

### 3.3 플랫폼 운영·개선 성과

#### 가. 매칭 시스템 연동

**질문형 매칭(8단계)**

1. 공정(업태) 선택
2. 주요 원단 선택
3. 지역(행정동) 선택
4. MOQ 선택
5. 재봉기 선택
6. 패턴기 선택
7. 특수기 선택
8. 생산 품목 선택

**자유 텍스트 매칭**
- 사용자가 자연어로 요구사항을 입력하면 업장 상세 전체 필드를 대상으로 키워드·동의어 매칭 수행
- 니트 관련 검색 시 「박원니트」 우선 노출 로직 적용

**주요 개선 사항(2026년 2~6월)**

| 일자(커밋) | 개선 내용 |
|------------|-----------|
| 3월~ | 자유 입력 매칭이 업장 상세 전체를 검색하도록 개선 |
| 4월~ | 매칭 결과 UI 정리, 점수 미산출 시 랜덤 추천 폴백 |
| 5월~ | 니트 관련 검색 시 박원니트 항상 노출 |
| 6월 | 메인·헤더 레이아웃 통일, AI 매칭 단일 메뉴 노출 |
| 6월 | 업장 카드 텍스트 여백 개선 |
| 6월 | 매칭 채팅 중복 메시지 버그 수정, 채팅 UI·헤더 AI 매칭 메뉴 강조 |

#### 나. UI/UX 개선
